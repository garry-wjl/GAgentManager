# 用户端重构 技术方案

## 1. 目标与范围

### 1.1 目标

- 将用户端从简单的单栏聊天页重构为三栏布局（会话列表 + 聊天区 + 文件面板），保留顶部导航栏
- 增强聊天体验：文件上传/预览、Agent 实时切换、消息引用/回复、对话分享、智能推荐 Prompt
- 完善个人中心：基础信息编辑、历史对话管理、安全设置
- 首屏加载 ≤ 2 秒，SSE 消息 ≤ 1 秒可见首字

### 1.2 范围

- **包含**：用户端前端完全重构 + 后端新增接口（文件上传、Agent 列表查询、对话分享、Prompt 推荐、设备管理）
- **不包含**：管理端功能、多 Agent 并发对话、付费/计费功能

### 1.3 设计约定确认

| 决策项 | 结论 |
|--------|------|
| 文件存储 | OSS/MinIO 对象存储 |
| Agent 选择器 | 新增专供用户端的 Agent 查询接口 |
| SSE 流式回复 | 本次新增 SSE 接口 |
| 自动 Agent 路由 | 基于消息内容语义分析自动选择 |
| 引用消息 | chat_message 表加 reply_to_message_id 字段 |
| 对话分享 | 新建 chat_share 表 |
| 文件上传 API | 独立上传接口（先上传获取 fileUrl，再发消息） |
| Prompt 推荐 | 新建 prompt_template 表，支持后端管理 |
| 设备管理 | 新建 user_device 表 |
| 历史分页 | 滚动到底加载更多 |
| 文件面板范围 | 仅当前会话的所有附件 |
| 分享页权限 | 需要登录才能查看 |

#### 3.2.2 领域规则

| 聚合/对象 | 规则类型 | 规则描述 | 违反时表达 |
|-----------|----------|----------|------------|
| ChatShare | 不变性 | shareToken 全局唯一 | 生成时加 UUID，唯一索引保护 |
| ChatShare | 业务规则 | 分享有效期 7 天 | expireTime = createTime + 7 天 |
| ChatShare | 业务规则 | 过期后不可访问 | isExpired 字段标记，查询时校验 |
| ChatMessage | 不变性 | replyToMessageId 必须属于同一会话 | 创建时校验目标消息 sessionId 一致 |

#### 3.2.3 领域动作

| 聚合/实体 | 领域动作 | 职责 | 前置条件 | 后置条件/规则 | 领域事件 |
|-----------|----------|------|----------|---------------|----------|
| ChatSession | replyMessage(content, replyToMessageId, operatorId) | 创建引用消息 | 会话归属用户 | 生成 ChatMessage 实体，replyToMessageId 指向原消息 | 无 |
| ChatShare | save(operatorId) | 创建分享 | 分享未过期 | 生成唯一 shareToken，设置 expireTime = now + 7 天 | SessionSharedEvent |
| ChatShare | invalidate(operatorId) | 使分享失效 | 分享存在 | isExpired = true | SessionShareInvalidatedEvent |
| ChatShare | incrementView() | 增加浏览次数 | 分享未过期 | viewCount++ | 无 |
